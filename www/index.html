# 电脑端一条命令（需要 Node.js ≥ 22） $ npx larkwire up

看 · 接 · 控

同一段 Agent 会话，三个主动权

👀

看

手机实时滚动电脑上的 Agent 输出。人出门了，活干完没有、卡在哪一步，掏出手机就知道。干完还能通知你。

🎙️

接

人离开电脑后，手机直接接管会话继续发话——不用冲回电脑前。电脑端在写半截话时绝不插嘴，双写不抢话。

✅

控

权限确认卡在手机上点允许或拒绝。杀了 App 也不怕，推送把卡片送到锁屏，点通知回来接着处理。

三步上手

全程不用注册账号、不用填手机号

  1. 手机装灵鹊 App
    iOS 走 TestFlight，Android 在应用市场下载
  2. 电脑跑 npx larkwire up，手机扫终端上的二维码
    扫码时手机和终端显示同一段公钥指纹，核对一致再确认
  3. 在电脑上正常开 Claude Code 干活
    会话自动出现在手机上，看 / 接 / 控随时可用

安全：中继是哑的

你的对话内容，除了你自己的设备，谁都看不到

🔒 端到端加密

手机与桥各自持有 X25519 密钥，每帧正文用 NaCl secretbox 加密。共享密钥从不经过中继。

🙈 中继零可见

中继只转发密文，开源可审计。它能看到的只有「哪台设备在线、帧多大、什么时间」。

🔑 配对防掉包

配对基于二维码 + 公钥指纹人工核对；桥侧密钥更新必须重新走公钥交换，防中间人替换。

⏱️ 离线暂存有期限

手机不在线时，密文帧最多暂存 10 分钟、每设备 50 帧；到期自动删除。
